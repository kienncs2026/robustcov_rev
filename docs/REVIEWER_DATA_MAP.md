# Data map: response letter (revision 1) -> files in this package

All experiments are launched with `python run_revision.py ...` (see `README_REVISION_VI.md`) or the scripts in
`tools/`. Every run directory under `results/<EXP>/runs/<run>/` holds `config.json`, `summary.csv` (energies,
audit statistics, acceptance), `solver_log.csv`, `trajectory.csv`, `power_covariance.csv`,
`pcrb_out_of_sample.csv`, `constraint_residuals.csv`, `iteration_log.csv`, and the Lemma 2/3 checks.
`paper_outputs/INDEX.csv` lists the aggregated tables; `paper_outputs/all_runs.csv` collects every run.
