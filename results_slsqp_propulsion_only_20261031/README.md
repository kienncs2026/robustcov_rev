# Propulsion-only rows with the submitted SLSQP search (superseded)

Two R2 propulsion-only runs made with `solver.propulsion_only_method = slsqp` (the search of the submitted
manuscript). SLSQP does not leave hover because the propulsion term is stationary at zero speed, so these
rows coincide with hover. They are superseded by the Powell rows in `results/R2/runs` and are kept only
for traceability.
